# 插件：多对象组合、协同与可分解性

触发：多个对象、资源、时段、区域或方案通过共同、分别、累计、覆盖、分配、调度或重叠组成总体结果。

## 不变量

先定义总体判据如何由单对象贡献组成，再决定能否拆分求解。不得把实现方便当作量词顺序、集合运算或可分解性的证据。

## 强制检查

1. 定义原子贡献 `P(i,x,t)`，把总体要求写成显式量词或聚合算子，如求和、并集、交集、最大/最小、至少 k 个或联合概率。
2. 区分 `forall x exists i` 与 `exists i forall x`，并明确重复是否计数。
3. 检查预算、容量、时序、互斥、同步、位置冲突和资源守恒等共享约束；目标可加不代表决策可分。
4. 用最小反例检查两类错误：单体均不满足但组合满足，以及集合重叠使直接求和偏大。
5. 检查空对象、单对象、完全重叠、互不重叠和交换标签等退化情形。

只有给出总体判据、分解构造、等价性理由并处理全部共享约束，才可逐对象求解后聚合。否则标记为受限模型或启发式方案，不得称为原问题的等价模型。

实现应保留重建联合判定所需的单对象贡献；独立验证从原子贡献重建总体结果，不复用求解器的聚合函数。量词、聚合或可分解性仍不明确且会改变答案时，作为 A 返回阶段 10。
