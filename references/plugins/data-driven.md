# 插件：数据驱动、预测与评价

触发：附件数据、回归、分类、聚类、预测、综合评价、拟合或机器学习。

## 强制检查

- 先做数据字典：字段含义、单位、缺失编码、时间/空间索引和目标变量来源。
- 检查缺失、重复、异常、样本不平衡和不可能值；处理方式必须可复现。
- 先划分训练/验证/测试，再拟合标准化、插补、特征选择和降维，防止数据泄漏。
- 时间或空间相关数据采用相应分组切分，不能默认随机独立同分布。
- 基准模型与复杂模型使用同一数据划分和同一指标。
- 指标定义、方向、分母、宏微平均和阈值必须明确；不能只报单一好看指标。
- 评价模型的权重、正负向处理和归一化需有依据，并做排序稳定性检查。
- 输出不确定性、残差诊断、外推范围和失效条件。
